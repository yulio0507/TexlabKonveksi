← Lihat website

1. Hubungkan GitHub

Admin ini menyimpan perubahan langsung ke repository website. Masukkan nama repository dan token akses GitHub saat akan mengelola konten.

Keamanan: token hanya disimpan sementara di memori halaman ini dan tidak ditulis ke file website. Jangan bagikan token kepada orang lain. Buat token dengan akses Contents: Read and write hanya untuk repository Texlab, lalu tutup halaman admin setelah selesai.

2. Kelola konten website

Pilih jenis konten untuk menambah, mengubah, atau menghapus produk katalog, foto portofolio, dan testimoni pelanggan.

Hubungkan GitHub terlebih dahulu untuk memuat konten.

Tambah konten

Pilih gambar baru untuk mengganti gambar. Jika dikosongkan, gambar lama tetap digunakan. Gunakan JPG, PNG, atau WebP dengan ukuran yang wajar (disarankan di bawah 2 MB).

Texlab Admin · Konten disimpan di file JSON dalam GitHub. Perubahan website tampil setelah hosting selesai deploy.
